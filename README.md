# US Stock Screener

미국 주식의 상대강도(RS)와 거래량 이벤트를 기반으로 매일 관찰할 종목군을 좁히는 개인용 스크리너입니다. 자동매매 시스템이 아니라 관심 종목 후보를 추리는 도구입니다.

설계 프레임은 **"거래량 이벤트로 주목 → RS로 우선순위"** 입니다. 이동평균 추세나 과열 여부는 배제 조건이 아니라 등급·경고 라벨로만 표시합니다. 근거는 [백테스트](#백테스트) 섹션 참조.

## 유니버스

시가총액 기준 미국 상위 ~1000개 보통주 (`data/tickers_us1000.csv`).
yfinance screen(NMS/NYQ 상장, 시총 내림차순)으로 수집하고 Wikipedia S&P 500/400 섹터 정보를 매핑합니다.

유니버스 갱신 (월 1회 권장):

```bash
UV_CACHE_DIR=/tmp/uv-cache uv run python scripts/fetch_universe.py
```

## 스크리너 실행

```bash
UV_CACHE_DIR=/tmp/uv-cache uv run python main.py
```

가격 데이터는 증분 동기화라 평소 ~10초, 당일 재실행 시 ~4초 소요됩니다(저장소가 비어 있으면 최초 전체 다운로드 ~2분).
결과는 아래 경로에 저장됩니다.

```
outputs/screener_universe_YYYY-MM-DD.csv    # 전체 평가 결과 (점수 포함)
outputs/screener_candidates_YYYY-MM-DD.csv  # 필터 통과 종목만
```

## 필터 로직

### 하드 필터 (3층)

| 순서 | 층 | 조건 |
|------|------|------|
| 1 | 유동성 | 20일 평균 거래대금 ≥ $50M |
| 2 | RS 필수 | 20일 SPY 대비 RS 변화율 > 0 |
| 3 | 주목 트리거 (5일 지속창) | 최근 5거래일(당일 포함) 내 트리거 발생 (아래) |

**당일 서지(surge)** — 거래량이 20일 평균의 1.5배 이상 5배 미만 + 당일 양봉
**지속 매집(acc)** — 최근 10일 중 매집일(가격↑ + 거래량 > 20일 평균)이 6일 이상

**지속창 (2026-08-21)** — 트리거가 뜬 종목은 이후 5거래일 동안 후보(관찰 종목군)에 유지됩니다. 단, 유동성·RS 조건은 매일 다시 충족해야 합니다. 근거: 신규 트리거 7,739건 지연 진입 백테스트에서 알파가 첫 2일 소폭 감쇠 후 7일까지 당일의 ~70% 유지. 효과: 후보 익일 생존율 45%→82%, 관찰군 ~100종목. `days_since_trigger`(경과일, 0=오늘 신규)와 `triggered_today` 컬럼으로 신선도를 표시합니다.

### signal_type

| 값 | 의미 |
|------|------|
| `surge+acc` | 서지·매집 동시 충족 — 백테스트상 가장 강한 신호 |
| `surge` | 당일 서지만 |
| `acc` | 지속 매집만 |

### 등급 (추세 컨텍스트)

**A** — 종가 > MA60 **AND** MA60이 10일 전보다 상승 (추세 순응)
**B** — 그 외 (하락·횡보 구간에서의 반등 성격)

MA 조건은 배제가 아니라 성격 구분입니다. 하락 국면에서는 B가 A보다 나은 구간도 있습니다(백테스트 참조).

### 경고 라벨 (배제 아님, `warnings` 컬럼)

| 라벨 | 조건 |
|------|------|
| `과열` | 종가 > MA20×1.25, 또는 5일 수익률 ≥ 40%, 20일 수익률 ≥ 60%, 당일 수익률 ≥ 25% |
| `거래량5x+` | 거래량 20일 평균 5배 이상 + 양봉 — 어닝스/뉴스 갭 의심 (트리거에서도 제외됨) |
| `분산N일` | 최근 10일 중 분산일(가격↓ + 거래량 > 20일 평균) 3일 이상 |
| `어닝스20일내` | 다음 실적 발표가 20거래일 내 (yfinance calendar, 후보만 조회) — 기술적 셋업과 별개의 이벤트 베팅임을 표시 |

### 점수 (v3, percentile 가중합)

전 종목에 부여되어 필터 통과 여부와 무관하게 순위를 볼 수 있습니다.

| 가중치 | 피처 |
|------|------|
| 25% | SPY 대비 RS 50D |
| 20% | SPY 대비 RS 20D |
| 20% | 상승일/하락일 거래량 비율 20D (`updown_vol_ratio_20d`) |
| 15% | 섹터 ETF 대비 RS 20D |
| 10% | 섹터 ETF 대비 RS 50D |
| 10% | RS선 50일 고점 근접 (`rs_spy_near_high`) |

2026-08-21 재검증(워크포워드 + Newey-West 보정 + 베타/섹터/변동성 조정 IC)에 따른 개편입니다. 매집일 수와 거래량 추세는 보정 후 예측력이 없어(t=1.27/0.46) 제거하고, 리스크 조정 후에도 살아남는 중기 RS 계열과 상승/하락일 거래량 비율(매집 강도의 상위 호환 지표)로 대체했습니다. `atr_ratio`(변동성)는 IC 최상위지만 절반이 베타 노출이라 계속 보류. 당일 봉 형태·베이스 안정성·MA 정배열·50일 고점 근접도는 여전히 제외(IC 0 근처 또는 음수).

여기에 **국면-등급 정합 보너스**(+0.10)가 더해집니다: `Confirmed Uptrend`의 A등급, `Market in Correction`의 B등급 후보는 점수가 0.10 가산됩니다. 국면별로 A/B 우열이 역전된다는 백테스트 결과(아래)를 반영한 소프트 틸트로, 후보를 제거하지 않고 정렬 우선순위만 조정합니다.

### score_3m (3개월 관점, 실험적 참고 컬럼)

12-1 모멘텀(최근 1개월 제외 12개월 SPY 상대 수익률) 60% + 6-1 모멘텀 40%의 percentile 가중합. 정렬에는 쓰지 않습니다. 60d 초과수익 IC +0.093(NW t=2.44), 십분위 스프레드 최상위 +9.4% vs 최하위 -1.1%. **주의**: 장기 모멘텀은 생존 편향이 가장 크게 부풀리는 지표라 상대 순위 비교 전용이며, 상장 12개월 미만 종목은 NaN. 계산에 2y 데이터가 필요합니다(`--period 2y`가 기본값).

### 트리거가 / 확장도

`trigger_price` = 가장 최근 거래량 트리거가 발생한 날의 종가(신호 원점), `ext_from_trigger` = 현재가/트리거가 − 1. "신호가 뜬 자리에서 얼마나 왔는지"를 보여주는 참조 앵커입니다.

**표시 전용이며 예측력은 없습니다** — 백테스트(71개 주간 스냅샷, 후보 관측치 7,564개)에서 확장도의 20d 초과수익 IC는 -0.03(t=-1.3, 비유의)이고 버킷별 성과도 비단조였습니다. 트리거일 저가 이탈을 손절 기준으로 쓰는 가설도 기각됐습니다(이탈 그룹이 오히려 +2.05% vs 유지 +1.01%). 구 매수기준가(MA20/60×1.01 눌림 기준)는 폐기 — MA 괴리가 클수록 오히려 수익이 좋아(IC +0.06, t=+1.8) "눌림 대기" 전략을 지지하는 근거가 없었습니다.

### 시장 국면 (3축 종합)

세 개의 독립 신호를 합산해 Confirmed Uptrend / Uptrend Under Pressure / Market in Correction을 판정합니다. 각 축의 의미:

| 축 | 무엇을 보나 | 왜 보나 |
|---|---|---|
| **추세** | SPY·QQQ가 MA60 위인가 (히스테리시스: -1% 밑 2일 연속이면 이탈, +1% 위면 복귀) | 시장의 큰 방향. 히스테리시스는 경계선 왕복으로 국면이 매일 뒤집히는 것을 방지 |
| **시장 폭** | 유니버스 1,000종목 중 MA60 위 비율 — **하한 감지기** (40% 미만이면 약세 투표, 그 외 중립) | 개별주 셋업이 먹히는 장인지 판별 — 후보 성과가 폭<40%에서만 붕괴(-3.2%), 그 위에선 폭 수준과 무관 (지수의 메가캡 왜곡도 보정) |
| **VIX 기간구조** | VIX ÷ VIX3M (0.95 미만 콘탱고 = 평온 / 1.0 초과 백워데이션 = 공포) | 옵션 시장이 매기는 즉각적 스트레스 — 가격·폭과 직교하는 제3의 시각 |

합산 +2 이상이면 상승장, -1 이하면 조정장이며, **새 국면이 3거래일 유지될 때만 전환**합니다(2년 검증에서 전환 27→14회). 국면은 후보를 제거하지 않고 등급 보너스(상승장→A, 조정장→B)와 판정 규칙에만 쓰입니다.

### 현재 로직 성과 (2025-02 ~ 2026-05, 63개 주간 스냅샷)

20일 SPY 대비 초과수익 평균 / 승률:

| 구분 | 20d 초과수익 | 승률 | 표본 |
|------|------|------|------|
| `surge+acc` | **+4.00%** | 59.8% | 194 |
| `surge` | +2.14% | 52.7% | 1,165 |
| `acc` | +1.26% | 52.7% | 1,073 |
| 후보 전체 (A) | +1.90% | 52.5% | 1,804 |
| 후보 전체 (B) | +1.90% | 55.3% | 628 |
| 비후보 | +0.35% | 47.6% | 56,255 |

시장 국면별 (20d): `Confirmed Uptrend`에서 A가 +2.51%로 우수하고, `Market in Correction`에서는 A가 +0.50%로 약해지는 반면 B가 +2.67%를 기록합니다. 이 역전이 국면-등급 정합 보너스의 근거입니다 — 저장 스냅샷 재정렬 비교에서 상위 10종목 바스켓 기준 +2.82% → +3.12%(승률 52.8% → 54.3%)로 개선됐습니다.

## 자동화

`launchd/` 에 실행 래퍼 스크립트가 있습니다 (macOS launchd 또는 cron에 연결).

```
launchd/run_screener.sh          # 스크리너 → AI 코멘터리 → 정적 사이트 빌드·푸시 (실패 시 30분 후 1회 재시도) → launchd/screener.log
launchd/run_fetch_universe.sh    # 유니버스 갱신 (월 1회) → launchd/fetch_universe.log
```

crontab으로 쓸 경우 (한국 시간 기준 평일 새벽 6시, 미국 장 마감 후):

```
0 6 * * 1-5  /Users/jhpark/Documents/Claude\ Code/US-stock-screener/launchd/run_screener.sh
```

대시보드의 "마지막 실행" 표시는 `launchd/screener.log` 를 읽습니다.

## 정적 배포 (Cloudflare Pages)

`scripts/build_site.py` 가 최신 결과를 서버 없이 동작하는 정적 미러로 변환해 `site/` 에 저장합니다 — 패치된 index.html(API 호출을 미리 구운 JSON으로 라우팅, 스크리너 실행 버튼 숨김) + `api/*.json` 번들 + 결과 CSV. 일일 자동화가 이 디렉터리를 커밋·푸시하면 깃헙에 연결된 Cloudflare Pages가 자동 재배포합니다(빌드 커맨드 없음, output directory `site`). 접근 제한은 Cloudflare Access(이메일 OTP)로 겁니다. 배포본은 읽기 전용 스냅샷이며 스크리너 실행은 로컬에서만 가능합니다.

## 가격 저장소

심볼당 parquet 1개를 유지하는 증분 저장소 (`price_store.py`, `.cache/price_store/daily/<SYMBOL>.parquet`, 최대 800거래일).

- 매일 마지막 저장일 이후만 다운로드하고, 앞 7일을 겹쳐 받아 저장분과 종가를 대조 — 어긋나면(배당·분할로 수정주가 재계산) 해당 종목만 자동 전체 리프레시. 별도의 주기적 전체 재다운로드가 필요 없습니다.
- 다운로드 실패는 배치 재시도(지수 백오프) → 종목 단위 재시도 → 그래도 실패하면 전일 저장분으로 대체하고 대시보드에 표시합니다.
- 강제 무효화가 필요하면 `.cache/price_store/` 삭제 후 재실행(전체 재다운로드 ~2분). 수동 동기화는 `uv run python scripts/update_prices.py` (`--full` 로 전체 리프레시).

## 기술 스택

- Python 3.12+, [uv](https://github.com/astral-sh/uv) 패키지 관리 (`pip install` 대신 `uv add`)
- yfinance (가격 데이터), pandas, numpy, pyarrow (parquet 저장소)
- 대시보드: 표준 라이브러리 `ThreadingHTTPServer` — HTML/CSS/JS 전체가 `dashboard.py`의 `INDEX_HTML` 문자열에 인라인 (외부 프레임워크·템플릿 파일 없음)
- 배포: Cloudflare Pages (정적 미러, `site/`) + Cloudflare Access
